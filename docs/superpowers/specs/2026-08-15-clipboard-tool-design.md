# 剪贴板历史与常用短语工具 — 设计文档

日期：2026-08-15
状态：待评审

## 1. 概述

在 Windows 上做一个常驻的剪贴板历史与常用短语工具：

- **剪贴板历史**：自动记录复制过的文本与图片，可浏览、搜索、一键粘贴。
- **常用短语**：按分类管理邮箱、地址、代码片段，点一下即可粘贴。

**目标用户**：个人开发者，在自己的 Windows 机器上使用。

**成功标准**：
1. 复制任意文本/图片后，能在浮窗里立刻看到并回贴。
2. 邮箱/地址/代码片段能按分类组织，单击即可粘贴到当前焦点窗口。
3. 按全局热键可随时呼出/隐藏面板。
4. 常驻后台、无边框半透明浮窗、体验流畅不打扰。

## 2. 技术选型

- **Electron** + **React**（Vite + TypeScript 搭建，`electron-vite` 脚手架）
- **粘贴注入**：`nut.js`（`@nut-tree-fork/nut-js`），向当前焦点窗口发送 `Ctrl+V`；若不可用则回退 `robotjs`。
- **剪贴板监听**：轮询 Electron `clipboard` 模块（500ms 间隔）+ 内容哈希去重。纯 Electron 实现，无需原生监听插件。
- **全局热键**：Electron `globalShortcut`（默认 `Ctrl+Shift+V`，可配置）。
- **数据存储**：主进程内用 `fs` 直接读写 JSON 文件（不引入数据库），图片存为 PNG 文件。
- **打包**：`electron-builder`，产出 Windows 安装包与免安装版。

选型理由：用户明确「好看好用优先、资源占用无所谓」，且机器已装 Node.js。Electron 的 Web 前端能以最低成本做出美观的浮窗面板。

## 3. 架构

Electron 双进程：

```
┌─ 主进程 (main) ───────────────────────────────────┐
│  clipboard-service  轮询剪贴板(文本/图片) → 去重 → 写入历史
│  paste-service      一键粘贴：写回剪贴板 → 注入 Ctrl+V
│  tray               系统托盘(显示/隐藏、置顶开关、退出)
│  global-shortcut    注册/注销 Ctrl+Shift+V 显隐热键
│  store              数据持久化(JSON + 图片文件夹)
│  ipc                与渲染进程通信(contextBridge)
└────────────────────────────────────────────────────┘
┌─ 渲染进程 (React) ─────────────────────────────────┐
│  无边框、置顶、半透明、可贴边的浮窗面板
└────────────────────────────────────────────────────┘
```

- 渲染进程通过 `preload.js` 暴露的白名单 API（`contextBridge`）与主进程通信，不直接触碰 Node。
- 每个服务单一职责、独立可测；`store` 是唯一接触磁盘的模块。

## 4. 数据模型

存储根目录：`%APPDATA%\clipboard-tool\`

### 4.1 `history.json` — 剪贴板历史

```json
[
  {
    "id": "uuid",
    "type": "text" | "image",
    "content": "文本内容 或 图片文件名(如 1692000000000.png)",
    "sourceApp": "复制的来源窗口标题",
    "ts": 1692000000000,
    "pinned": false
  }
]
```

- 上限 **200 条**，超出淘汰最旧（置顶项不淘汰）。
- 连续重复内容自动去重（相邻两条相同则只保留一条）。
- 图片文件存 `images/` 目录，`content` 只存文件名引用。

### 4.2 `snippets.json` — 常用短语

```json
[
  {
    "id": "uuid",
    "group": "邮箱 | 地址 | 代码片段 | ...",
    "title": "工作邮箱",
    "content": "john@example.com"
  }
]
```

- `group` 为分类，默认提供「邮箱 / 地址 / 代码片段」，支持增删改。
- 代码片段为多行文本，原样保留缩进。

### 4.3 `settings.json` — 设置

```json
{
  "hotkey": "Ctrl+Shift+V",
  "alwaysOnTop": true,
  "historyLimit": 200,
  "autoHideOnPaste": false,
  "theme": "light" | "dark"
}
```

## 5. 功能规格

### 5.1 剪贴板监听
- 主进程每 500ms 读取剪贴板文本与图片。
- 与上一条记录比对（文本比内容、图片比内容哈希），相同则忽略。
- 记录来源窗口标题（`sourceApp`）。
- 变化后写入历史并推送给渲染进程刷新。

### 5.2 剪贴板历史
- 浮窗「历史」Tab 展示按时间倒序的历史列表。
- 单击条目 = 一键粘贴（见 5.4）。
- 悬停条目显示「置顶 / 删除」；置顶条目置顶展示，不随上限淘汰。
- 支持图片条目，列表显示缩略图。

### 5.3 常用短语
- 浮窗「短语」Tab 按 `group` 分组展示。
- 单击短语 = 一键粘贴。
- 支持新增/编辑/删除短语与分类；底部「+ 新增」入口。

### 5.4 一键粘贴
- 主进程 `paste-service`：把目标内容写回剪贴板 → 用 `nut.js` 向当前焦点窗口发送 `Ctrl+V`。
- 注入失败（目标窗口不支持）→ 回退「仅复制」并在右下角提示「已复制，请手动粘贴」。

### 5.5 搜索
- 面板顶部搜索框，实时过滤当前列表：
  - 历史：按文本内容、来源窗口标题匹配。
  - 短语：按标题、内容匹配。
- 搜索框获得焦点时可通过键盘上下键选择、回车粘贴、Esc 清空。

### 5.6 全局热键显隐
- 默认 `Ctrl+Shift+V` 呼出/隐藏浮窗；设置里可改。
- 注册失败（热键被占用）时托盘提示并在设置里警告。

### 5.7 系统托盘
- 托盘图标，右键菜单：显示/隐藏、置顶开关、历史条数上限、退出。

## 6. UI 布局

```
┌──────────────────────────────────────┐
│  🔍 搜索          [🔧][—][×]         │  ← 搜索框 + 设置/最小化/关闭
├────────────┬─────────────────────────┤
│  短语       │  邮箱                   │
│   · 邮箱    │   ┌──────────────────┐ │
│   · 地址    │   │ john@example.com │ │  ← 单击即粘贴
│   · 代码片段│   └──────────────────┘ │
│  历史       │   ┌──────────────────┐ │
│            │   │ 📝 文本 / 🖼 图片 │ │
│  [+ 新增]   │   └──────────────────┘ │
└────────────┴─────────────────────────┘
```

- 无边框、可拖拽、可贴屏幕边缘吸附、可调透明度。
- 单击条目即粘贴，面板保持常驻（默认不自动收起）；显隐由热键/关闭按钮控制。若设置 `autoHideOnPaste=true` 则粘贴后自动收起。
- 置顶条目带图标标记。

## 7. 错误处理

- 剪贴板监听异常：捕获并重试，不阻塞主流程。
- 历史/短语 JSON 损坏：启动时校验，失败则备份原文件并重建空数据。
- 图片粘贴到不支持目标：降级「复制图片 + 提示手动粘贴」。
- 热键被占用：注册失败时托盘提示，设置页标红。
- 敏感内容：本次不做自动排除；数据结构保留 `sourceApp`，为后续「排除密码管理器来源」开关预留。

## 8. 测试策略

- **单元测试**（Vitest）：剪贴板去重逻辑、历史上限淘汰、分类/短语增删改、搜索过滤。
- **主进程集成测试**：store 读写与损坏恢复。
- **手动测试清单**：剪贴板监听（文本/图片）、一键粘贴注入、全局热键、托盘菜单、贴边吸附、图片缩略图。

## 9. 非目标（本次不做）

- 剪贴板多设备同步、云同步。
- 敏感内容自动排除（仅预留字段）。
- 变量占位符（日期/时间/光标）。
- 代码片段语法高亮。
- 富文本/文件格式的剪贴板记录（仅文本 + 图片）。
